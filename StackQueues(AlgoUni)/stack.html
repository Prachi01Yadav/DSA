Mastering Stacks & Queues

A comprehensive guide to recognizing patterns, mastering techniques, and cracking coding interviews.

How to Recognize a Stack/Queue Problem

  • LIFO (Last-In-First-Out): If you need to "undo" something or access the most recently processed element.
  • Dependency on Neighbors: If the current element depends on its immediate predecessor or successor (e.g., matching brackets).
  • Monotonic Behavior: If you need to find the "next greater" or "previous smaller" element.
  • Recursive Nature: Any iterative solution that replaces a recursive DFS usually uses a Stack.
  • BFS / Level Order: If the problem asks for the "shortest path" in a graph or processing items level-by-level, use a Queue.

1. Monotonic Stack Pattern

This is the most frequent interview pattern. You maintain a stack in strictly increasing or decreasing order.

Use Case: Next Greater Element, Largest Rectangle in Histogram, Trapping Rain Water.

Template Logic: 

for (int i = 0; i < n; i++) {
    while (!stack.isEmpty() && arr[stack.peek()] < arr[i]) {
        // We found the next greater element for stack.peek()
        int index = stack.pop();
        result[index] = arr[i];
    }
    stack.push(i);
}

2. Bracket Matching / String Manipulation

Using a stack to manage state while parsing a string.

Common Questions:
  • Valid Parentheses: ()[]{}
  • Simplify File Path: /a/./b/../../c/
  • Decoded String: 3[a2[c]]

Pro-Tip: Use a Map to store opening and closing bracket pairs for cleaner code.

3. Infix, Postfix, and Prefix

Understanding how computers evaluate expressions. Shunting-Yard Algorithm is the core technique here.

Type Example Logic
Infix a + b Human readable. Requires operator precedence.
Postfix a b + Stack-friendly. Push operands; Pop twice on operator.
Prefix + a b Reverse the string and treat similarly to postfix.
Basic Postfix Evaluation:
  1. Scan string from left to right.
  2. If operand: push(operand).
  3. If operator: val1 = pop(), val2 = pop(), push(val2 operator val1).

4. Sliding Window Maximum (Queue/Deque)

Using a Double-Ended Queue (Deque) to find the maximum in every sliding window of size K.

The Technique: Maintain a deque of indices such that the values are in decreasing order.
  • Remove indices that are out of the current window.
  • Remove values from the back that are smaller than the current element (they will never be the maximum).
  • The front of the deque is always the maximum.

5. Interview Cheat Sheet: High-Frequency Questions

  • Easy: Implement Stack using Queues (and vice versa), Min Stack (GetMin in O(1)).
  • Medium: Daily Temperatures, Online Stock Span, Largest Rectangle in Histogram, Circular Queue.
  • Hard: Max Sliding Window, Trapping Rain Water, Basic Calculator (I, II, III).
